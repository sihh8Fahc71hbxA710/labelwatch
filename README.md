# ラベルウォッチ v1.6（Web版）

時間管理（ストップウォッチ・集計・カレンダー）と家計簿（入力・予算・総資産）のアプリです。iPhoneのSafariで動き、ホーム画面に追加すると普通のアプリのように使えます。

## 特長

- **通信しない**：ページに通信禁止の設定（Content-Security-Policy の `connect-src 'none'`）が入っています。記録を外へ送ることは、ブラウザの仕組み上できません。
- **広告・解析ツールなし**：外部のライブラリやフォントも読み込みません。
- **記録は端末の中だけ**：記録はこのiPhoneのブラウザ内に保存されます。バックアップ（JSON）の書き出しと読み込みができます。
- **オフラインで起動**：一度開けば、電波がなくても起動します。

## iPhoneだけで公開する手順（GitHub Pages・無料）

1. ファイルアプリでzipをタップして展開すると、「labelwatch」フォルダができます。
2. Safariで github.com を開いてログインします。
3. 右上の「＋」→「New repository」を開きます。Repository name に `labelwatch` と入れ、**Public** を選んで「Create repository」を押します。
4. 「uploading an existing file」→「choose your files」を押します。labelwatchフォルダの中のファイル7個をすべて選び、下の「Commit changes」を押します。
   - ボタンが見つからない時は、アドレスバーの「ぁあ」→「デスクトップ用Webサイトを表示」に切り替えてください。
5. リポジトリの「Settings」→ 左のメニューの「Pages」を開きます。Branch を「main」「/ (root)」にして「Save」を押します。
6. 1〜2分待つと `https://（ユーザー名）.github.io/labelwatch/` で開けるようになります。

## ホーム画面に追加（ここから使い始めてください）

1. Safariで上のURLを開きます。
2. 共有ボタン →「ホーム画面に追加」を選びます。
3. 以後はホーム画面のアイコンから起動します。

> **注意**：Safariのタブとホーム画面のアプリでは、データの保存場所が別々です。記録はホーム画面のアプリで付けてください。ホーム画面から使うほうが、データも消えにくくなります。

## 使い方

- **左上の☰**：時間管理と家計簿を切り替えます。
- **右上の歯車**：設定です（円グラフの表示、カテゴリと目標時間、タスクの色、初期基準CF、家計簿のカテゴリ、税引後の表示、有料版の機能、データ）。
- **歯車の左の↶（時間管理のときだけ）**：1つ前の状態に戻します。戻せるのは1つ前までです。計測中のものは開始時刻から計算し直すので、経過時間はそのぶん進んでいます。
- **時間管理**：ストップウォッチ／集計／カレンダー。
  - カテゴリの最初の並びは、仕事・休憩・家事・運動・趣味・睡眠・入浴です（以前の最初の並びのまま使っていた場合は、更新時にこの並びにそろえます。↶で戻せます）。
  - 「編集」で色のボタンを押すと色を変えられます。行を長押しして上下に動かすと、並び順を変えられます。
  - カテゴリごとに目標時間（1日・1週・1か月、以上・以内）を決められます。
  - タイマーは「今日の累計」を表示します。同じカテゴリはまとめて数え、タスクは「同じカテゴリ・同じタスク名」ごとにまとめます。中断して再開しても0には戻りません。累計は0時にリセットされます。
  - 集計の「記録」は、今まで通りラベルを切り替えた区切りごとに別々に残ります。右にスワイプしても消せます（直後の「取り消し」で戻せます）。
- **タスク**：ストップウォッチの下とカレンダーに、同じ「今日のタスク」と「未完了のタスク」（昨日以前に始めて終わっていないもの）が出ます。
  - 右のボタンで「着手」→「中断」→「再開」→「中断」…と進みます。左の「完了する」を押すと線が引かれ、「完了済み」になります。
  - タスクに着手すると「タスクモード」になります。ストップウォッチの背景が青になり、「スタート」が「中断／再開」に、「破棄」が「タスクを完了する」に変わって、タスクのボタンと同じ動きをします。タスクを完了すると元に戻ります。
  - 中断すると、自動で別のカテゴリ（最初は「休憩」）の計測に切り替わります。切り替え先は、各タスクの「中断したら →」で選べます。「無選択」にすると切り替えずにタイマーを止め、ストップウォッチは普通の表示に戻ります。
  - 「終了したら →」で、完了したあとに続けるもの（無選択・カテゴリ・別のタスク）を選べます。最初は「無選択」で、完了するとタイマーは止まります。
  - 開始日・終了目標・期限を決められます。終了目標を過ぎると黄色、期限の24時間前から赤、期限を過ぎると灰色になります（設定で色を付けないこともできます）。
  - タスクで計った記録は「仕事：TOEIC（タスク）」のように表示されます。
- **集計**：いちばん下の赤い「記録をすべて削除する」で、時間管理の記録をまとめて消せます（カテゴリ・タスク・予定はそのまま。直後なら↶で戻せます）。
- **カレンダー**：日・週・月で切り替えられます。決まった時間の「予定」も登録できます（集計には入りません）。
- **家計簿・入力**：支出（左）・投資（中央）・収入（右）。口座間の振替もできます。
- **家計簿・予算**：月ごと・カテゴリごとに予算と残りを表示します。
- **家計簿・総資産**：現金＋預金の合計と推移を表示します。有料版の機能をオンにすると、株・債券・投資信託の評価額と資産比率も表示されます。
- **はじめに**：設定 →「初期基準CF」で、使い始めた日の現金と銀行の残高を入れてください。

### 有料版の機能について

投資の記録・評価額・資産比率は「有料版」の機能として作ってあります。このWeb版は自分用なので、設定の「有料版の機能」をオンにするだけで使えます（料金はかかりません）。時価（株価・基準価額など）は手入力です。

## バックアップ

ホーム画面のアイコンを削除したり、Safariの「履歴とWebサイトデータを消去」を行ったりすると、記録は消えます。ときどき設定 →「書き出し・読み込み」→ バックアップを書き出して、ファイルアプリなどに保存してください。バックアップには時間管理と家計簿の両方が入ります。

## プライバシーについて

- アプリ自身は通信しません（`connect-src 'none'`）。
- GitHub Pagesは、アプリのファイルを配信するだけです。ページを開いた時や更新を確かめる時には、GitHubへのアクセスが発生します。これは一般的なWebサイトと同じアクセス記録で、記録の中身が送られることはありません。
- リポジトリは公開になりますが、公開されるのはアプリのプログラムだけです。あなたの記録は含まれません。

## 前の版から更新するとき

同じリポジトリにファイルを上書きでアップロードしてください。次か、その次の起動時に新しい版に切り替わります。今までの記録はそのまま使えます（念のため、先にバックアップを書き出しておくと安心です）。
